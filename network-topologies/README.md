# Network Topologies - Simulation Only

This folder will hold Cisco Packet Tracer topology notes and configuration
blueprints for the 2026 Independent Simulation Lab.

Current status: No Packet Tracer project files have been uploaded yet.
Topology design in this portfolio is simulation only:
- 3-switch star topology, enterprise access layer simulation
- Dynamic VLAN interfaces, IP subnet blocks, standard ACLs regulating inter-VLAN traffic
- No physical switch configuration, no production network

Upload a Packet Tracer (.pkt) file here only after it has been built and tested locally.
Do not commit real network addresses, credentials, or production topology data.
