### Access Layer Network Topology Design (Cisco Packet Tracer)
This module tracks my simulated network design schema mapping baseline enterprise environments:

- **Topology:** 3-switch star topology, simulating the enterprise access layer.
- **VLAN Layout:** Segregates local test boundaries to prevent broadcast domain leakage. Dynamic VLAN interfaces, IP subnet blocks.
- **Access Control Lists (ACLs):** Standard ACLs regulating inter-VLAN traffic. Restricts non-essential port communication across simulated server management networks.
- **Interface Metrics:** Models standard server host port allocations over copper media connections.
